## 1. Observable Opstra Data Flow & Network Architecture

During authorized browser inspection of `https://opstra.definedge.com/options-simulator`, all option-simulator interactions are driven by six read-only REST endpoints:

1. **Instrument Universe (`GET /api/optionsimulator/tickers`)**
   - Returns an array of 212 NSE underlying ticker strings (`NIFTY`, `BANKNIFTY`, `FINNIFTY`, and 209 NSE stock F&O symbols).
   - *Limitation observed on Opstra:* Does not include BSE derivatives (`SENSEX`, `BANKEX`). IWSM extends this dynamically via Alice Blue `NFO` + `BFO` contract masters.

2. **Expiry Catalogue (`GET /api/optionsimulator/updatedsimulatorexpiries`)**
   - Returns `{ nfoweeklies, nfomonthlies, bnfweeklies, finexpiries, midcpexpiries, lastexp }`.
   - Individual stock F&O symbols bind to `nfomonthlies` (`eqexpiries`), whereas indices bind to their respective weekly + monthly series.

3. **Spot / Futures / IV / Lot Metadata (`GET /api/strategybuilder/spot/<TICKER>&<EXPIRY>`)**
   - Returns `{ SpotPrice, futuresPrice, iv, ivPercentile, lotsize, strikes }`.
   - Triggered when switching `Select Index/Stock` or `Select Expiry` in live/reference setup.

4. **Session Timestamp Index (`GET /api/optionsimulator/timestamps/<TICKER>&<START_ISO>&<END_ISO>`)**
   - Returns `{ timestamps: [unix_epoch_seconds...] }` at 1-minute resolution (`09:16` to `15:30 IST`) across valid trading sessions.

5. **Timestamped Option Chain (`GET /api/optionsimulator/optionchain/<UNIX_TS>&<TICKER>&<EXPIRY>`)**
   - Returns `{ spotPrice, futuresPrice, iv, lotsize, optionchaindata: [...] }`, where each strike row contains `{ Strikes, CallLTP, CallIV, CallDelta, CallOI, CallVega, PutLTP, PutIV, PutDelta, PutOI, PutVega }`.
   - *Important Behavioral Observation:* For stock F&O in historical simulator mode (e.g., `RELIANCE`, `HDFCBANK`), Opstra returns `spotPrice: 0` and uses `futuresPrice` as the underlying pricing anchor. IWSM preserves real underlying spot prices wherever available and cleanly falls back to futures when spot is absent.

6. **Strategy Payoff Evaluation (`GET /api/optionsimulator/payoff/<TICKER>$<LEGS_SPEC>$<PAYOFF_DATE>$<VAR_IV>$<VAR_SPOT>$<VAR_DTE>$<UNIX_TS>`)**
   - Triggered whenever a leg is added, toggled, edited, reversed, exited, deleted, or stepped forward/backward in time.
   - Returns `{ DTE, breakevens, chart: [{ StockPrice, Change, Today, Final, bes }] }`. IWSM computes all payoff curves, breakevens, standard-deviation cones, and BSM/Black-76 Greeks deterministically in `js/options-paper-analysis.js` and `js/options-simulator-engine.js` with zero server round-trip latency.
